SMART STAROSTA v10 — ҮШ ТІЛ ЖӘНЕ КЕШІГУ УАҚЫТЫ
================================================

БҰЛ НҰСҚА НЕ ІСТЕЙДІ?
- 🇰🇿 Қазақша, 🇷🇺 Орысша, 🇬🇧 Ағылшынша тіл ауыстырғышы қосылады.
- Староста күнделікке «Кешікті» деп сақтаған студентке сағат/минутты қоса алады.
- Бөлім меңгерушісі өз бөліміне тіркелген топтардың кешігулерін қарай алады.
- Жеке кешігулер Excel (.xlsx) файлын жүктей алады.
- Бұрынғы қатысу белгілерін, есептеу алгоритмін және жеке жазбаларды өзгертпейді.

ТҮЗЕТУ ӘДІСІ — БІР JAVASCRIPT ФАЙЛЫН ҚОСУ
1. GitHub-тағы репозиторийге smart-starosta-v10.js файлын жаңа файл ретінде жүктеңіз.
2. Бұрынғы index.html файлын ашыңыз (Edit).
3. </body> тегінің ДӘЛ АЛДЫНА мына жолды қойыңыз:

   <script type="module" src="./smart-starosta-v10.js?v=10"></script>

4. Commit changes басыңыз. GitHub Actions-та жариялануын күтіңіз.
5. Firebase Console → Firestore Database → Rules ашып,
   FIRESTORE-RULES-КОСУ.txt ішіндегі «match /reports/{ownerUid}/lateArrivals/{entryId}»
   блогын бұрыңғы ережелердің ІШІНЕ қосыңыз; бұрынғы ережелерді жоймаңыз.
6. Publish басыңыз.
7. Браузерде сайтты Ctrl+Shift+R арқылы жаңартыңыз.

ҚАЛАЙ ПАЙДАЛАНАДЫ?
Староста:
1. Әдеттегі логинімен кіріп, «Қатысу журналы» ашыңыз.
2. Студентке «Кешікті» деген белгі қойып, күнделікті сақтаңыз.
3. Беттің төменгі оң жағындағы «Кешігу уақыты» батырмасын басыңыз.
4. Күнді, студентті таңдаңыз да, сағатты (мысалы, 09:15) енгізіңіз.
5. «Уақытты сақтау» басыңыз. Уақыт Firebase-де сақталады.

Меңгеруші:
1. Меңгеруші логинімен кіріңіз.
2. «Кешігу уақыты» батырмасын басыңыз.
3. Сол бөлімнің топтары бойынша барлық жазба шығады.
4. «Кешігулер Excel» батырмасын бассаңыз, .xlsx жүктеледі.
