SMART STAROSTA v6 — АККАУНТ АУЫСТЫРҒАНДА СҰРАҚ ШЫҚПАЙДЫ

ДҰРЫС ЖҮКТЕУ (бұрынғы файлдардың орнына):
1) ZIP архивін ашып, барлық файлдарды жеке таңдаңыз. ZIP архивінің өзін GitHub-қа салмаңыз.
2) GitHub → my-kundelik → Add file → Upload files. index.html, cloud.js, cloud-v6.js,
   sw.js, manifest.json және екі PNG файлды репозиторийдің ең жоғарғы деңгейіне жүктеңіз.
3) GitHub Files changed/Commit changes арқылы бұрынғыларын ауыстырыңыз.
4) Actions → pages build and deployment → Successful тексеріңіз.
5) Сайтты Chrome-да инкогнито арқылы ашып, логин терезесінің төменінде «v6» екенін көріңіз.
6) Телефонда ескі нұсқа тұрса: iPhone Safari немесе Android Chrome арқылы жаңа сайтты
   қайта ашыңыз; ескі PWA-ны жойып, жаңа нұсқасын қайта орнатуға болады.
7) Мәлімет жоғалмасын десеңіз, браузердің Clear site data/Очистить данные пәрменін
   пайдаланбаңыз. Сақталған топтарды JSON-ға экспорттау ұсынылады.

НЕ ТҮЗЕТІЛДІ:
- Тіркелу мен кіруде ескі құрылғы деректерін көшіру ұсынылмайды.
- Аккаунттан шыққанда да modal/confirm сұрағы көрсетілмейді.
- Әр аккаунттың деректері Firebase UID бойынша бөлек сақталады.
- Браузерге v6 cloud-v6.js жеке жаңа файл ретінде беріледі, сондықтан ескі cloud.js
  кэші қолданылмайды.
- Service Worker жаңарған кезде ескі Smart Starosta кэштерін өшіреді,
  бірақ localStorage-тегі пайдаланушы мәліметтерін қозғамайды.
- Аккаунттың әр өзгерісі интернет болса жіберіледі; интернет жоқта сол UID-дің
  жергілікті көшірмесі сақталады. Басқа аккаунтқа импортталмайды.

ҚОСЫМША:
- Ескі JSON файлды қолмен импорттау батырмасы сақталған және оны әдейі басқанда
  импортты растау сұралуы мүмкін. Ол аккаунт ауыстыру процесіне қатыспайды.
- Firestore Rules өзгерту қажет емес, бұрынғы жеке пайдаланушы ережелері қолданылады.
