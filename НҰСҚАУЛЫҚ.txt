SMART STAROSTA — ОНЛАЙН КҮНДЕЛІК
=================================

1. FIREBASE БАПТАУ
   https://console.firebase.google.com/ → mykundelik
   Authentication → Sign-in method → Email/Password → Enable → Save
   Firestore Database → Create database → Standard → Production mode
   Firestore Database → Rules → осы ZIP ішіндегі firestore.rules файлының
   бүкіл мәтінін көшіріп, PUBLISH басыңыз.
   Authentication → Settings → Authorized domains бөлімінде қажет болса
   dzondzon771-rgb.github.io доменін қосыңыз (https:// жазбай).

2. GITHUB PAGES
   GitHub → dzondzon771-rgb/my-kundelik репозиторийіне кіріңіз.
   ZIP архивінің ІШІНДЕГІ мына файлдарды репозиторийдің негізгі бөлігіне
   (root) жүктеңіз (ZIP файлын тікелей жүктемеңіз):
       index.html
       cloud.js
       manifest.json
       sw.js
       icon-192.png
       icon-512.png
   Егер index.html GitHub-та бар болса, ескісін ауыстырыңыз.
   firestore.rules және НҰСҚАУЛЫҚ.txt жариялау үшін қажет емес.
   Settings → Pages → Deploy from a branch → main → /(root) → Save.
   Сайт: https://dzondzon771-rgb.github.io/my-kundelik/

3. ҚОЛДАНУ
   Сайтты ашып → Тіркелу → email + құпиясөз.
   Әр аккаунттың күнделігі БӨЛЕК сақталады.
   Жаңа аккаунтта нақты адамдардың аты-жөні емес, үлгі деректер ашылады.
   Оларды өзгертіңіз немесе бұрынғы күнделікті JSON арқылы импорттаңыз.
   Белгілер мен кесте өзгерсе, жоғарғы жолақтағы «Онлайн сақталған»
   мәтінін тексеріңіз.
   Басқа телефонда сол email және құпиясөзбен кірсеңіз, сол күнделік ашылады.
   Android: Chrome → ⋮ → Install app / Басты экранға қосу.
   iPhone: Safari → Бөлісу → Add to Home Screen.

4. МАҢЫЗДЫ
   - Бір күнделікті бірнеше аккаунтпен бірлесіп өңдеу әлі жоқ:
     әр аккаунт тек өз күнделігін көреді.
   - Бір аккаунтпен екі құрылғыда бір уақытта өзгеріс енгізсеңіз,
     соңғы сақталған өзгеріс басым түсуі мүмкін.
   - Firestore бір құжаттың максималды көлемі 1 MiB; үлкен күнделіктер
     үшін деректерді күндерге бөліп сақтау қажет болады.
   - Бұрынғы браузерде сақталған деректер жаңа аккаунтқа алғаш кіргенде
     сұрау арқылы импортталады (егер сол сайттың localStorage-інде болса).
   - Интернетке алғаш кіру және аккаунт ашу үшін байланыс қажет.
     Интернет үзілсе мәлімет құрылғыға уақытша сақталады; қайта қосылған
     кезде синхрондауға әрекет жасалады.
   - GitHub Pages — сайтты орналастыру, Firebase — аккаунт пен дерекқор.
   - Қолданба ресми Play Market / App Store дүкендеріне жүктелмейді:
     бұл телефонға орнатылатын PWA.
