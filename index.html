Алдымен файлды таңда.

3. GitHub-қа екі файл керек: жаңа index.html және smart-starosta-v10.js (егер бұрын жүктеген болсаң, қайта жүктеу қажет емес).

  1. GitHub → my-kundelik репозиторийі → index.html → Download raw file.
  2. Осы түзеткіштен index.html файлын таңдап, жасалған жаңасын жүкте.
  3. GitHub репозиторийіне түзетілген index.html файлын жүктеп, ескісін ауыстыр. Commit changes бас.
  4. Сайтты Ctrl+Shift+R арқылы жаңарт; тіл мен кешігу уақыты батырмасын тексер.
