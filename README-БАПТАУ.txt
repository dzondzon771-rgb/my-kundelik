SMART STAROSTA v8 — БӨЛІМ МЕҢГЕРУШІСІ: ТОЛЫҚ ЕСЕП ЖӘНЕ EXCEL
================================================================

ЖАҢА МҮМКІНДІКТЕР
1) Меңгеруші өз бөліміне тіркелген барлық топты көреді.
2) Әр топта «Толық қарау» және «↓ Excel» батырмалары бар.
3) Топ ішінде студенттер бойынша қорытынды, студенттің күн сайынғы тарихы,
   күндер бойынша қорытынды және әр күндегі барлық студенттің белгісі ашылады.
4) Әр топтың Excel (.xlsx) құжатында 4 парақ болады:
   «Жалпы есеп», «Студенттер», «Күндер», «Қатысу журналы».
5) Басталу/аяқталу күндерін көрсетсеңіз, экран да, Excel де сол мерзімге сүзгіленеді.
6) Старостаның өз күнделігін жүргізу логикасы өзгертілмеді.
7) Меңгеруші тек көре алады, журналды өзгерте алмайды.

ФАЙЛДАРДЫҢ АРХИВІН ТОЛЫҚ КӨШІРІҢІЗ; ZIP ФАЙЛЫНЫҢ ӨЗІН САЙТ РЕТІНДЕ ЖҮКТЕМЕҢІЗ.

FIREBASE КІРУ ЖӘНЕ БӨЛІМ РҰҚСАТЫ
- Firebase Authentication -> Users: меңгерушінің жеке email және құпиясөзі.
- Firestore staffRoles/{МЕҢГЕРУШІ_UID} құжаты:
     role            = department_head
     departmentId    = dept-01
     departmentName  = бөлім атауы
- departments/dept-01/members/{СТАРОСТА_UID} құжаты:
     label = топ атауы   (қажет болғанда)
- firestore.rules: осы ZIP ішіндегі нұсқасын Firestore Database -> Rules
  бөліміне жариялау керек, егер v7 ережелері әлі орнатылмаса.
- Әр староста Firebase-ке өз күнделігін сақтауы керек.

ҚАУІПСІЗДІК
- Excel файлы тек кіруге рұқсаты бар меңгерушінің браузерінде жасалады.
- Ол Firebase-тің reports құжаттарынан есеп алады, жеке diary/notes ашылмайды.
- Рөлді пайдаланушы өзі бере алмайды. Рөл мен мүшелік тізімін тек Firebase
  жобасының иесі Console арқылы бекітеді.
- Excel ішінде студенттердің мәліметтері бар. Оны рұқсатсыз таратпаңыз.

ЕГЕР ӘЛІ v7 / v6 КӨРІНІП ТҰРСА
- GitHub Actions жариялауы Successful болғанын тексеріңіз.
- Компьютерде: F12 -> Application -> Service Workers -> Unregister.
- Application -> Cache Storage ішінен ескі Smart Starosta кэштерін тазалаңыз.
- Ctrl+Shift+R арқылы жаңартыңыз.
- «Clear site data» баспаңыз: сақталмаған жергілікті мәліметтер жоғалуы мүмкін.

EXCEL ҚАЛАЙ ЖҮКТЕЛЕДІ
1) Бөлім меңгерушісінің email/паролімен кіріңіз.
2) Қажет болса жоғарғы басталу/аяқталу күндерін таңдаңыз.
3) Топ жолындағы «↓ Excel» басыңыз. .xlsx файлы жүктеледі.
4) Немесе «Толық қарау» -> «Осы топты Excel-ге жүктеу» басыңыз.
5) Толық қарап шығу үшін топтың студенттер/күндер кестелеріндегі «Қарау» басыңыз.

ТЕКСЕРУ
- Интерфейс пен жүктеу механизмдері үлгі деректермен браузерде тексерілді.
- Excel файлының 4 парағы және .xlsx пішімінің жарамдылығы тексерілді.
- Нақты Firebase есептерін көру сіздің жарияланған Rules және members тізіміне тәуелді.
