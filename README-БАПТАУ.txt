SMART STAROSTA v9 — КЕЛДІ / КЕЛМЕДІ, ДҰРЫС EXCEL ЖӘНЕ ҚАТЫСУ ПАЙЫЗЫ
=====================================================================

НЕ ТҮЗЕТІЛДІ
1. Excel-дегі студент саны, келді/келмеді саны енді % түрінде көрсетілмейді.
2. Қатысу пайызын тек нақты белгі қойылған жағдайлар бойынша есептейді:
   КЕЛДІ / (КЕЛДІ + КЕЛМЕДІ) × 100.
3. Бұрынғы белгілерді жоғалтпай, негізгі Excel парағында мыналар көрінеді:
   - Қатысты немесе Кешікті -> КЕЛДІ
   - Себепті немесе Себепсіз келмеді -> КЕЛМЕДІ
   - Белгі жоқ -> БЕЛГІ ЖОҚ (пайыз есебіне кірмейді)
4. Себеп, кешігу туралы нақты дерек Excel-дің «Толық журнал» парағында сақталады.
5. Әр топтың Excel құжатында 5 парақ бар:
   - Жалпы есеп (мәндер + есептеу ережесі + белгі толтырылу пайызы)
   - Студенттер (әр студенттің келген/келмеген саны мен %)
   - Күндер (әр күннің келген/келмеген саны мен %)
   - Қатысу кестесі (күндер бойынша түсінікті жасыл/қызыл кесте)
   - Толық журнал (күн, студент, қатысты ма, нақты түсіндірме)
6. Бөлім меңгерушісі әр топты жеке қарайды және .xlsx жүктейді.
7. Мерзім сүзгісі экрандағы және экспортталатын есепті өзгертеді.
8. Старостаның күнделігі мен Firebase рөл жүйесі өзгермейді.

ҚАТЫСУ % ТҮСІНДІРМЕСІ
Егер 3 белгі болса: 2 КЕЛДІ, 1 КЕЛМЕДІ, нәтиже 2/3 = 66,7%.
Белгі жоқ күн — келген де, келмеген де емес, сондықтан % есебіне кірмейді.
Осыны жасырып қалмау үшін жеке «БЕЛГІ ЖОҚ» және «Белгілердің толтырылуы»
көрсеткіштері қосылған. Бір күнде бірнеше студент болса, пайыз барлық
студент-күн белгілерінің негізінде есептеледі (күндер санын жай бөлу емес).
Ескерту: Қазіргі деректер құрылымында әр студент үшін бір күнге бір белгі бар;
егер әр пән/сабақ бойынша бөлек қатысу керек болса, деректер моделін өзгерту қажет.
