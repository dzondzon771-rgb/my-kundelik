SMART STAROSTA v9.5 — ТҮПНҰСҚА ДИЗАЙН + НАҚТЫ GEMINI ЖИ
===========================================================

Бұл v9.4 түпнұсқа React дизайнының жалғасы. Күнделік, мәзір, сабақ кестесі,
журнал, меңгеруші панелі, үш тіл, кешігу сағаты, Excel — БҰРЫНҒЫ КҮЙІНДЕ.
Қосылғаны — оң жоғарғы жолдағы «✦ AI талдау» батырмасы.

ЖИ ЕКІ НӘРСЕ ІСТЕЙДІ
1. «ЖИ-мен талдау»: қатысу сандарының заңдылықтарын қысқаша талдап,
   нақты ұсыныстар дайындайды.
2. «Есеп мәтінін жазу»: меңгеруші немесе староста үшін редакциялауға болатын
   дайын есеп мәтінін құрастырады.

ЖИ-ге ЖІБЕРІЛМЕЙДІ: студенттердің аты-жөні, UID, email, жеке жазбалар,
құпиясөз, кешігу сағаты. ТЕК топтың қысқа атауы және қатысу агрегаттары
(келген, келмеген, кешіккен, белгісіз, % және күндер бойынша сан) жіберіледі.
ЖИ ешқандай журналды өзгерте алмайды. Жауапты адам тексеруі керек.

ҚАТЫСУ ПАЙЫЗЫ (бұрынғыдай):
(қатысқан + кешіккен) / (қатысқан + кешіккен + келмеген + себепті келмеген)
× 100%. Белгі жоқ күндер бөлек көрсетіледі.

GEMINI-НІ НАҚТЫ ҚОСУ — FIREBASE-ТЕ БІР РЕТ БАПТАУ КЕРЕК
1. Firebase Console -> mykundelik жобасы -> AI Services -> AI Logic
   -> Get started -> Gemini Developer API таңда. Қажетті API-ларды қос.
   Нұсқаулық: https://firebase.google.com/docs/ai-logic/get-started?platform=web

2. Firebase Console -> App Check -> Apps бөлімінде осы ВЕБ-ҚОСЫМШАНЫ
   reCAPTCHA Enterprise арқылы тірке. Кілтті Google Cloud reCAPTCHA
   Enterprise ішінен алу қажет болуы мүмкін. Рұқсатты домен:
      dzondzon771-rgb.github.io
   Нұсқаулық: https://firebase.google.com/docs/app-check/web/recaptcha-enterprise-provider
   App Check AI Logic үшін міндетті, жарамды App Check токенінсіз
   Gemini сұранысын Firebase бұғаттайды.

3. Сайтқа кір -> «✦ AI талдау» -> «Баптау» -> reCAPTCHA Enterprise
   САЙТ КІЛТІН енгіз (Site key, Secret key ЕМЕС) -> «Сақтау».
   Бұл кілт осы браузерде сақталады. Осыдан кейін «ЖИ-мен талдау»
   немесе «Есеп мәтінін жазу» бас.

   Барлық құрылғыда кілт бірден жұмыс істесін десең, ai-assistant.js
   файлының басындағы PUBLIC_APP_CHECK_SITE_KEY = '' өрісіне
   осы ЖАРИЯЛЫ site key мәнін жазып, GitHub-қа файлды жаңартуға болады.
   SITE key құпия емес, бірақ Gemini API key / service-account key
   сияқты құпия кілттерді ЕШҚАШАН GitHub-қа салуға болмайды!

4. Егер Gemini қате көрсетсе, Firebase AI Logic қосулы ма, App Check
   тіркелді ме, домен дұрыс па, тариф/квота жетеді ме — тексер.
   AI model атауы: gemini-3.5-flash-lite (файлдың басында өзгертсе болады).
   Қызметтің квоталары/ақылы мүмкіндіктері болуы мүмкін.

НЕЛІКТЕН КІШКЕНЕ ЕКІ ФАЙЛ ҚОСЫЛДЫ?
Түпнұсқа React дизайнын бұзбай AI функциясын қосу үшін екі оқшауланған
файл жасалды. Олар бастапқы панельдің CSS-ін, JS кодын ауыстырмайды.

НЕГІЗГІ НҮКТЕ
- Староста өз күнделігінің сандық қатысу көрсеткішін талдайды.
- Бөлім меңгерушісі өзіне рұқсат етілген топтардың статистикасын талдайды.
  «Толық қарау» ашса — сол топ, ал жалпы тізімде — сүзгідегі топтар.
- Ешқандай Firestore жаңа коллекциясы, құпия API кілті қажет емес.
- Firestore Rules бұрынғы v9.4 нұсқасында қалай дұрыс жұмыс істесе,
  солай қалуы тиіс. Мұндағы firestore.rules — ТЕК БҰРЫНҒЫ КӨШІРМЕ.
- Firebase Authentication аккаунттарын, Firestore students/users/reports/
  staffRoles/departments деректерін ӨШІРМЕ!

ТЕКСЕРУ МӘРТЕБЕСІ
- React түпнұсқа дизайны және меңгеруші панелі: браузерде тексерілді.
- Starosta және admin AI статистикасы: тесттік деректермен тексерілді.
- Gemini prompt: тесттік модельмен тексерілді; аттар мен notes жіберілмейді.
