SMART STAROSTA v9.4 — ТҮПНҰСҚА ДИЗАЙНДЫ САҚТАҒАН ЖАҢАРТУ
=============================================================
Бұл жинақ сіз жіберген ТҮПНҰСҚА v9 Smart Starosta React файлына негізделген.
Сайттың бүйірлік мәзірі, карточкалары, түстері, сабақ кестесі, жазбалары,
студенттер тізімі, Firebase аккаунттары, меңгеруші панелі сақталған.
Жаңа v11/v12 дизайны немесе app.js қажет ЕМЕС.

НЕ ҚОСЫЛДЫ
1. Қазақша / орысша / ағылшынша ауыстырғышы.
   Тіл таңдағышы бұрынғы «ҚАЗ» белгісінің орнында. Логин мен меңгеруші
   беттеріне де шағын тіл таңдағыш қосылды.
   Негізгі мәзір/батырма/тақырыптар аударылады; толық мәтіннің кейбір
   ұзын сөйлемдері қазақша қалуы мүмкін — негізгі React құрылымы өзгермеді.
2. Староста журналында «Кешікті» белгісін басқанда оның қасында
   сағат/минут енгізетін өріс пайда болады. Мысалы, 09:15.
3. Меңгеруші осы нақты уақытты студенттің тарихынан және күндік есептен көреді.
4. Топтың Excel есебінде кешігудің уақыты, «Кешігулер» парағы бар.
5. Старостаның күндік есебі CSV орнына нақты Excel (.xlsx) болып жүктеледі:
   күн DD.MM.YYYY мәтінімен сақталады, сондықтан ######## болмайды.
6. Меңгеруші панелінің бұрынғы CSS файлы index.html ішіне де енгізілді:
   сыртқы head-dashboard.css кешігіп жүктелсе де, көрініс бұзылмайды.

FIREBASE — МІНДЕТТІ БІР РЕТ ЕРЕЖЕНІ ЖАҢАРТУ
1. Firebase Console -> mykundelik -> Firestore Database -> Rules ашыңыз.
2. Бұрынғы ережелердің сақтық көшірмесін көшіріп алыңыз.
3. Архивтегі firestore.rules нұсқасымен салыстырыңыз. Өзге ережелерді
   өшірмей, reports/{studentUid} құжатының data ішіне
   «lateTimes» өрісіне рұқсат қосыңыз.
   Архивтегі нұсқада бұрынғы жазбаларға рұқсат сақталған.
4. Publish басыңыз. Жай GitHub-қа firestore.rules жүктеу Firebase
   ережелерін ӨЗГЕРТПЕЙДІ!
5. Староста кіреді -> «Кешікті» -> нақты уақыт -> автоматты сақталуын
   тексереді. Содан кейін меңгеруші -> Толық қарау -> студент тарихын ашады.

КЕШІГУДІ САҚТАУ ФОРМАТЫ
- Жеке күнделік: users/{uid}/private/diary.data.lateTimes[YYYY-MM-DD][studentId]
- Бөлім есебі: reports/{uid}.data.lateTimes[YYYY-MM-DD][studentId]
- Бөлім меңгерушісі тек өз бөлімінің reports құжаттарын көреді.
- Жеке notes жазбалары есепке жіберілмейді.

НЕНІ ӨШІРМЕУ КЕРЕК
- Firebase Authentication аккаунттарын / Firestore студент, топ,
  departments, staffRoles, users, reports құжаттарын ӨШІРМЕҢІЗ!
- Ескі жергілікті дерек пен JSON резерв көшірмені жоймаңыз.
- Нақты Firebase тіркелгісінде бастапқы деректерді көріп тексеріңіз.

ТЕКСЕРУ
- Түпнұсқа React бүйірлік мәзір, кесте, карточка дизайны браузерде ашылды.
- Тілдер ауысты, кешігу 09:15 болып JSON-да сақталды.
- Меңгеруші студент тарихында 09:15 уақытын көрді.
- Excel файлдары файл пішімін тексеруден өтті (күн DD.MM.YYYY).
- Браузер сынағы үлгі деректермен өтті; сіздің нақты Firebase
  аккаунттарыңыз бен GitHub Pages жариялауын тексеру қажет.
