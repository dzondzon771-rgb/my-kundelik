Smart Starosta — Excel v10 (тек 2 файл)

GitHub-та тек report-excel.js және head-dashboard.js файлдарын ауыстырыңыз.
Басқа файлдарға тимеңіз.

Excel-де ТЕК «Толық журнал» парағы болады.
Жолдар: күні, нөмірі, студент, КЕЛДІ / КЕЛМЕДІ / БЕЛГІ ЖОҚ, топ.
Қорытынды сол парақтың ТӨМЕНГІ жағында орналасады.
Пайыз = КЕЛДІ / (КЕЛДІ + КЕЛМЕДІ) × 100.
Белгі жоқ жазбалар пайызға кірмейді.
Қатысу мәртебесі жоқ болса, пайыз «—» болады.
